내 비밀값

    
MCP 가 쓰는 키(GitHub·Confluence 토큰 등)는 코드에 넣지 말고 kit-mcp.json 의 "secrets": ["API_TOKEN"] 에 이름만 적습니다
      (사내 Git 은 GITHUB_ 로 시작하는 이름을 받지 않으니 {"env": "GITHUB_TOKEN", "name": "GH_TOKEN"} 처럼 다른 이름으로 넣고 이어 줍니다).
      값은 사내 Git 비밀값에 넣으면 mcp-test 가 실행할 때 MCP 에만 넘깁니다(화면에서 다시 볼 수 없음).
